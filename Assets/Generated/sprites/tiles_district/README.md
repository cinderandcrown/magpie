# District tiles (Higgsfield)

Per art folder (`downtown`, `docks`, `factory`):

- `platform.png` — solid ground fill (preferred by `makePlatformTileSet`)
- `crate.png`, `ledge.png`, `vent.png`, `ladder.png`, `rooftop.png` — decor
- optional `fire-escape.png` (downtown)

Mapped via `ArtLibrary.artFolder(for:)` same as parallax backgrounds.
